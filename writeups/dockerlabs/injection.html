Explotación

Puedo ver que hay un panel de login dentro, instantáneamente me viene a la mente el intentar un SQLinjection, para ello una forma de comprobar si existe esta vulnerabilidad es simplemente poner una ' en el campo de usuario. Si existe una vulnerabilidad tipo SQLinjection me devolverá un error.

Se puede ver como salta un error no contemplado de SQL. Así que pruebo las inyecciones más comunes

Escalada de privilegios

Ejecuto find / -perm -u=s -type f 2>/dev/null para poder buscar binarios explotables

Veo que puedo usar el binario /usr/bin/env para generar una shell con root.

Ejecuto env /bin/sh -p y obtengo root del sistema.
