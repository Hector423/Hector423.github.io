Obsession

Reconnaissance

Inicio con un escaneo con nmap para poder saber que servicios tiene la maquina.

En los puertos abiertos, puedo comprobar que la máquina tiene: ftp, ssh y http. Voy a empezar con el servicio de ftp

Exploración servicio FTP

Me doy cuenta en el escaneo de nmap de que el servicio de ftp tiene habilitado el inicio de sesión anónimo, y que este tiene permisos de lectura para dos archivos .txt.

Efectivamente puedo acceder, voy a leer el contenido de los dos archivos.

Importante
De los dos archivos se puede sacar que existen dos usuarios: Gonza y Russoki y que hay algunos permisos mal configurados en el equipo.

Exploración servicio HTTP

Antes de intentar realizar fuerza bruta con algunos de los dos usuarios, voy a investigar el servicio de http para ver si puedo obtener más información

El servicio de http lleva a la página por defecto de apache, así que voy a realizar una enumeración de directorios con gobuster para ver si hay algo oculto.

Importante
Consigo sacar dos rutas nuevas ocultas: /backup y /important

En el de backup nos confirma la existencia del usuario russoski y que este se usa para todos los servicios.

Y en el de important sale un manifiesto hacker

Explotación

Una vez comprobado todo el servicio de http, decido realizar un ataque de fuerza bruta con el usuario de russoski

Obtengo la contraseña del usuario russoski: iloveme

Usuario y contraseña
Usuario: russoski
Contraseña: iloveme

Voy a usar las credenciales para iniciar sesión en el servicio ssh

Escalada de privilegios

Dentro del sistema puedo ver archivos interesantes.

Aunque me quedo con que el usuario russoski puede ejecutar /usr/bin/vim como superusuario.

Ejecutando el siguiente código como administrador obtengo el acceso al superusuario.

sudo vim -c ':!/bin/sh

Con este comando lo que consigo es crear una shell de root usando vim

Una vez ejecutado si ejecuto whoami me responde con el usuario root, obteniendo acceso completo al sistema.
