Reconnaissance

Empiezo el escaneo con nmap para ver que puertos tiene abiertos

Veo que tiene el puerto 22 para ssh y el 80 para http, decido mirar la página web para obtener más información

A simple vista no parece que tenga nada, investigo el código de la página por si hay algo oculto

Consigo dos posibles nombres de usuario, Juan y Camilo, voy a probar estos nombres con el servicio ssh

Escalada de privilegios

Empiezo a intentar escalar privilegios

Realizo una búsqueda de binarios y de permisos para el usuario camilo, no encuentro nada relevante, solo un usuario más llamado pedro.

Como en el mensaje que he encontrado antes mencionaban un correo, voy a ver si hay algo en /var/mail que me pueda servir

Efectivamente encuentro un correo y dentro hay una contraseña.

Como el mensaje de antes era del usuario Juan, la contraseña deberá de ser de ese usuario.

La pruebo con el usuario juan y consigo el acceso

Intento buscar formas de escalada con el usuario juan y me encuentro que tiene un permiso de superusuario para ejecutar ruby sin contraseña. Según gtfobins si ejecuto el siguiente comando:

ruby -e 'exec "/bin/sh"'

Podré obtener una shell como root, así que la ejecuto i obtengo el root del sistema
